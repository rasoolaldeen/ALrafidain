بوابة الرافدين - نسخة النشر

الملفات:
- index.html : الموقع
- data.json : الإعدادات المركزية

طريقة التحديث:
1. افتح الموقع وسجل الدخول كمالك.
2. عدّل الإعدادات.
3. من النسخ الاحتياطي اضغط تصدير؛ سينزل ملف باسم data.json.
4. استبدل data.json الموجود في مستودع GitHub بالملف الجديد.
5. بعد نشر GitHub Pages وإعادة تحميل الصفحة سيقرأ المستخدمون الإعدادات الجديدة.

مهم: لا تنشر المستودع على أنه آمن للأسرار. كلمات المرور الموجودة في data.json يمكن تقنياً قراءتها من ملفات الموقع المنشورة. الحماية الحقيقية للملفات تبقى بصلاحيات Google Drive.
